# Dibacii Technologies logo

This directory is an isolated extraction of the logo mark and wordmark from the `alpha` branch.

## Files
- `dibacii-logo.svg` — the original two-path symbol (upper sail and lower swoosh).
- `css/dibacii-logo.css` — logo presentation, hover treatment, responsive sizing, reduced-motion handling, and the 30-second emergence animation.
- `index.html` — standalone preview.

## Animation
The animation is CSS-only in the source implementation, so there is no logo-specific JavaScript to copy. The upper sail rotates once; the lower swoosh rotates twice. Both scale forward during the turn and settle back into place before the next 30-second cycle.

Open `index.html` directly to preview the isolated logo.
